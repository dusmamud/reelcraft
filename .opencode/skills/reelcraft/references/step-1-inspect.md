# Step 1: Inspect the Project

Before writing a single line of script or code, analyze the target codebase to find its viral core.

## The 8-Point Reel Inspection Rubric

Answer these questions before storyboarding:

1. **What is the single sentence that makes someone stop scrolling?**
   - Bad: "A modular, scalable framework for building full-stack web applications."
   - Good: "This 200-line script replaces an entire $5,000 SaaS platform."

2. **What is the enemy or villain?**
   - The enemy isn't a person; it's a painful workflow, an overpriced subscription, legacy boilerplate, slow build times, or unmanageable bugs.

3. **What is the visually strongest artifact in this project?**
   - A clean UI screenshot?
   - A satisfying terminal log?
   - A high-speed benchmark comparison chart?
   - An intuitive 5-line code snippet?

4. **Who is the exact viewer?**
   - Junior developers learning to code?
   - Senior engineers looking for developer tools?
   - Tech founders / indie hackers wanting fast MVPs?
   - AI enthusiasts curious about autonomous agents?

5. **What is the product's actual superpower?**
   - Is it 10x faster?
   - Is it zero-config?
   - Is it 100% open-source / free?
   - Does it run locally without APIs?

6. **What is the tangible proof?**
   - Number of lines of code, render time in milliseconds, GitHub stars, or before/after diff.

7. **What is the language preference?**
   - English (Global tech audience) or Hindi/Hinglish (Massive Indian tech creator community).

8. **What action should the viewer take at the end?**
   - Star on GitHub, comment a keyword to get the code, or follow for daily breakdowns.
