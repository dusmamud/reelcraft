# Reelcraft Plan: StepGaana

## What is this app?
StepGaana is an AI-powered music studio based on StepAudio 3's `step-music` model that allows users to describe music in words and hear a complete song, generate instrumentals, arrange vocals into music, and create music covers.

## The angle
"Describe in words, hear a complete song." A tangible, artisanal music studio experience meets cutting-edge generative audio AI. The contrast between vintage vinyl craftsmanship (spinning disc, needle drop, tonearm) and instantaneous AI music generation.

## Hook (first 2-3 seconds)
Big, clean headline over a dark gallery backdrop:
"What if you could turn words into music?"
A stylized vinyl record silhouette reveals with a warm bronze glow.

## Key moments (the middle)
- **Prompt input simulation:** "Moody midnight lo-fi jazz with bansuri..." typing out in the studio prompt box.
- **The 4 Creation Modes:** Sequential arrival of feature chips:
  1. 🎵 Song Creation (text-to-music)
  2. 🎹 Instrumental Generation
  3. 🎙️ Vocal-to-Music Arrangement
  4. 💿 Music Covers & Remixing
- **The Vinyl Needle Drop & Waveform:** Tonearm swings in, vinyl record starts spinning, and dynamic waveform peaks illuminate with artwork-derived accents.

## Outro / punchline
"Describe in words, hear a complete song."
StepGaana · StepAudio 3 Studio
Built by Dus Mamud
CTA: Start Creating Today · stepgaana.app

## User flow worth showing
Type prompt "Moody midnight lo-fi jazz with bansuri" → Select creation mode [Song Creation] → Needle drops on spinning vinyl → Complete song stream with real-time waveform visualization.
