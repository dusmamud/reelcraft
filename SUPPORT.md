## 🐛 Reporting Bugs

If you encountered a bug or unexpected behavior:
1. Search existing [GitHub Issues](https://github.com/dusmamud/reelcraft/issues) to see if it's already reported.
2. Run `npx reelcraft doctor` to collect system diagnostic information.
3. Open a new issue at [github.com/dusmamud/reelcraft/issues/new](https://github.com/dusmamud/reelcraft/issues/new) including:
   - Your OS and Node.js version
   - Exact command executed
   - Terminal output or stack trace
   - Expected vs. actual behavior

## 💡 Requesting Features & Templates

Have an idea for a viral motion graphics hook, new TTS voice provider, or sound effect pack?
- Submit a feature request on [GitHub Issues](https://github.com/dusmamud/reelcraft/issues).
- Describe the use case and how it enhances video retention and developer workflows.
